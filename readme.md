# Drive KKTC v2 — Northern Cyprus Scenic Driving Routes & Heritage Discovery

A modern TypeScript + React + Vite monorepo showcasing curated scenic driving routes, historical landmarks (Soli Ancient Theatre, Lefke Aqueduct, Karpaz Peninsula, Sadrazamköy, Değirmenlik), and travel guides across Northern Cyprus (KKTC).

## Featured Route Categories

- **Coastal & Peninsula Drives**: Karpaz Peninsula Night Sky, Sadrazamköy coastal cliffs.
- **Historical & Archaeological Heritage**: Soli Ancient Roman Theatre, Lefke Aqueducts.
- **Mountain & Village Trails**: Değirmenlik & Besparmak mountain passes.

## Getting Started

### Prerequisites
- Node.js v18+
- `pnpm` (`npm install -g pnpm`)

### Installation & Local Development
```bash
pnpm install
pnpm --filter @workspace/drive-kktc run dev
```
Open `http://localhost:5173` in your browser.

### Typecheck & Production Build
```bash
pnpm run typecheck
pnpm run build
```
